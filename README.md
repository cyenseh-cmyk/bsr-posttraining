# Behaviorally Sufficient Rank of LLM Post-Training Updates

HDDA research project investigating the behaviorally sufficient rank of post-training weight updates in Qwen3-0.6B.

The project compares SFT and GRPO updates and analyzes their singular spectra using methods including:

- Marchenko–Pastur thresholding
- Optimal Hard Thresholding
- 95% explained variance
- Behavioral rank evaluation on GSM8K
